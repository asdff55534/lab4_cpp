## Задача 1.9

**Условие**

Создать класс `Point` для представления точки на координатной плоскости. 
Класс должен содержать поля `x` и `y` типа `double`, не менее трёх конструкторов, методы для получения и изменения координат,
а также перегруженный оператор вывода для отображения полей объекта.

Согласно варианту необходимо вычислить расстояние от точки до начала координат. 
Результат должен иметь тип `double`. Вводимые данные необходимо проверять на корректность.

**Алгоритм решения**

1. Объявить класс `Point` с закрытыми полями `x` и `y`.
2. Реализовать конструктор по умолчанию, конструктор с параметрами и конструктор копирования.
3. Реализовать методы `getX`, `getY`, `setX` и `setY`. В сеттерах проверять, что координаты являются конечными числами.
4. Перегрузить оператор `<<` для вывода координат точки.
5. Реализовать метод для вычисления расстояния от точки до начала координат по формуле  
   `d = √(x² + y²)`.
6. В главной функции создать объекты разными конструкторами, проверить работу методов и ввести координаты с клавиатуры.

## Задача 2.9

**Условие**

Добавить к классу `Point` перегруженные операции согласно варианту:

- унарная операция `--` уменьшает координаты `x` и `y` на 1;
- унарная операция `-` меняет координаты `x` и `y` местами;
- неявное преобразование в тип `int` возвращает целую часть координаты `x`;
- явное преобразование в тип `double` возвращает координату `y`;
- вычитание целого числа уменьшает координату `x`;
- вычитание одной точки из другой вычисляет расстояние между точками и возвращает вещественное число.

В главной функции продемонстрировать работу операций с понятными сообщениями пользователю.

**Алгоритм решения**

1. Перегрузить префиксную и постфиксную операции `--`. Обе операции уменьшают координаты точки на 1.
2. Перегрузить унарную операцию `-`, возвращающую новую точку с переставленными координатами.
3. Реализовать неявное преобразование объекта `Point` в `int`, возвращающее целую часть `x`.
4. Реализовать явное преобразование объекта `Point` в `double`, возвращающее `y`.
5. Перегрузить операцию вычитания целого числа из точки. Результатом должна быть новая точка с уменьшенной координатой `x`.
6. Перегрузить операцию вычитания двух точек. Результатом должно быть расстояние между ними.
7. Проверить результаты всех операций в главной функции.
