## Задача 1.9

**Условие**

Создать класс `Point для представления точки на координатной плоскости. 
Класс должен содержать поля `x` и `y` типа `double`, не менее трёх конструкторов, методы для получения и изменения координат,
а также перегруженный оператор вывода для отображения полей объекта.

Согласно варианту необходимо вычислить расстояние от точки до начала координат. 
Результат должен иметь тип `double`. Вводимые данные необходимо проверять на корректность.

**Алгоритм решения**
1. Создать класс Point для хранения координат точки на плоскости.
2. Добавить конструкторы для создания точки без координат, с заданными координатами и для копирования другой точки.
3. Добавить методы для получения и изменения координат, предусмотрев проверку вводимых значений.
4. Предусмотреть вывод координат точки.
5. По координатам точки определить длину гипотенузы прямоугольного треугольника. Эта длина равна расстоянию от точки до начала координат.
6. В главной функции проверить работу конструкторов и методов, ввести координаты с клавиатуры и вывести найденное расстояние.

## Задача 2.9

**Условие**

Добавить к классу `Point` перегруженные операции согласно варианту:

- унарная операция `--` уменьшает координаты `x` и `y` на 1;
- унарная операция `-` меняет координаты `x` и `y` местами;
- неявное преобразование в тип `int` возвращает целую часть координаты `x`;
- явное преобразование в тип `double` возвращает координату `y`;
- вычитание целого числа уменьшает координату `x`;
- вычитание одной точки из другой вычисляет расстояние между точками и возвращает вещественное число.

В главной функции продемонстрировать работу операций с понятными сообщениями пользователю.

**Алгоритм решения**

1. Дополнить класс Point операциями, указанными в варианте.
2. При уменьшении точки на единицу уменьшать обе её координаты на единицу.
3. При смене знака точки менять координаты x и y местами.
4. При преобразовании точки в целое число возвращать целую часть координаты x, а при преобразовании в вещественное число — координату y.
5. При вычитании целого числа из точки уменьшать координату x на это число.
6. При вычитании одной точки из другой вычислять расстояние между ними.
7. В главной функции ввести точки и целое число, выполнить каждую операцию и вывести полученные результаты.
